How it works

        
Each tournament has a folder in your GitHub repo (photos/t1/, photos/t2/, etc.) and a photos.json file that lists which images to show.

        
This helper generates that JSON for you — no manual editing required. Just list the filenames you uploaded and paste the result into GitHub.

        
Supported formats: .jpg, .jpeg, .png, .gif, .webp
